# HyperBoost

Усилитель громкости для HyperOS (стиль HyperOS 4, нижняя панель Liquid Glass).

## Сборка через GitHub
1. Создай репозиторий и залей все файлы (папка `.github` обязательна).
2. Вкладка **Actions** → **Build APK** → **Run workflow** (или просто сделай push в `main`).
3. После сборки скачай артефакт **HyperBoost-apk** → внутри `app-debug.apk`.
4. Установи APK, дай разрешения (Bluetooth, уведомления).

## На Xiaomi/HyperOS
Настройки → Приложения → HyperBoost → Автозапуск ВКЛ, Экономия заряда → «Нет ограничений», закрепи приложение в «Недавних».
